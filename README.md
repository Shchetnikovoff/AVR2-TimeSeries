## 1. Описание временного ряда

Суточный минимум температуры воздуха, Мельбурн (Австралия), 01.01.1981, 31.12.1990. Источник: метеослужба Австралии BOM, файл `daily-min-temperatures.csv` из открытого набора Jason Brownlee (https://github.com/jbrownlee/Datasets). Копия исходного файла лежит в `data/daily-min-temperatures.csv`, подготовленный ряд в `data/melbourne_tmin_daily_processed.csv` (сохраняется кодом ноутбука).

Характеристики ряда: 3652 календарных дня, среднее 11.18 C, стандартное отклонение 4.07 C, минимум 0.0 C, максимум 26.3 C. Ряд с сильной годовой сезонностью (январь около 15.0 C, июль около 6.7 C) и слабой недельной динамикой. Практический смысл: прогноз минимальной температуры нужен энергетике (нагрузка на отопление/охлаждение) и сельскому хозяйству (заморозки).

## 2. Постановка задачи

Прогноз на h = 90 дней вперед по дневным данным. Разбиение фиксированное: train, первые 3562 дня (1981, 02.10.1990), holdout, последние 90 дней (03.10.1990, 31.12.1990). Метрики на holdout: RMSE, MAE, MAPE (одно нулевое значение и значения менее 0.5 C из знаменателя исключены, ряд содержит значения около нуля зимой), sMAPE. Надежность проверяется тремя способами: rolling-бектест (3 окна по 90 дней со сдвигом 90), покрытие интервалов 80/95, анализ остатков лучшей модели (график ACF + тест Ljung-Box числом).

## 3. EDA

Пропуски: в исходном файле отсутствуют 2 календарные даты (1984 и 1988 годы), ряд достроен до полного дневного диапазона и пропуски заполнены линейной интерполяцией. Дубликатов дат нет, типы: дата + float. Временной шаг после предобработки строго суточный.

Стационарность: тест Дики-Фуллера на уровнях дает статистику -4.44 при p-value 0.00025, ряд стационарен, порядок интегрирования d = 0 (это обосновывает ARIMA без разностей ниже).

Сезонность: ACF(365) = 0.48, ACF(180) = -0.48 (полугодовой противофазный пик), распределение по месяцам подтверждает годовой цикл. Декомпозиция (аддитивная, период 365): сезонная компонента доминирует, тренд слабый. PACF: лаг 1 доминирует (0.77), значимые лаги до 7 включительно (это обосновывает ручной AR(7) ниже).

Графики: `img/01_series.png` (весь ряд), `img/02_seasonality.png` (боксплоты по месяцам + среднегодовые), `img/03_decomposition.png` (тренд/сезонность/остаток), `img/04_acf_pacf.png` (ACF до 400 лагов, PACF до 30).

## 5. Анализ производительности

Rolling-бектест, 3 окна по 90 дней, средний RMSE (`results/metrics_backtest.csv`): ML-HGB 2.582, DL-MLP 2.599, ML-RF 2.660, HoltWinters 2.664, ML-Ridge 2.708, Theta/AutoTheta 2.726, DL-NHITS 2.882, DL-LSTM 3.355, ARIMA 3.363, AutoARIMA 3.423, SeasonalNaive 3.595, AutoETS 3.731, Naive 3.915.

Два честных наблюдения. Первое: LSTM лучший на holdout (2.669), но девятый в бектесте (3.355), сеть переобучается под конкретное окно. Второе: самый стабильный, ML-HGB (2.770 на holdout, 2.582 в бектесте, первое место), рядом HoltWinters (2.721 и 2.664). Порядок семейств подтверждается обоими замерами: ML и сезонные статметоды впереди, ARIMA и наивные позади.

Вероятностные оценки: интервалы HoltWinters на holdout, покрытие 80% интервала 0.811, покрытие 95% интервала 0.933 (`results/coverage.csv`, график `img/07_intervals.png`). Покрытие совпадает с номиналом с точностью до 0.02, интервалам можно верить.

Анализ остатков лучшей модели (DL-LSTM на holdout): среднее 0.067 C (смещения нет), std 2.720, Ljung-Box(10) p-value 0.00041, в остатках осталась значимая автокорреляция (`results/residuals.csv`, `img/08_residuals_acf.png`). То есть даже лучшая модель не вычистила всю структуру, в ряде есть зависимость, которую LSTM за 500 шагов не забрал. Это не провал, а зафиксированный предел точности: RMSE 2.669 против std ряда 4.07.

Время счета (замерено кодом): stat 100 c, ML 5 c, DL 76 c, бектест stat 283 c / ML 11 c / DL 77 c.
