## Описание проекта

Проект посвящён анализу и прогнозированию временных рядов с использованием различных статистических и машинных методов.

### Задачи:
- Загрузка и предобработка данных временного ряда
- Разведочный анализ (EDA)
- Декомпозиция временного ряда на компоненты (тренд, сезонность, остаток)
- Проверка стационарности (тест Дики-Фуллера)
- Построение прогнозов с использованием 4 моделей:
  1. **ARIMA** (Auto-Regressive Integrated Moving Average)
  2. **Holt-Winters** (Экспоненциальное сглаживание)
  3. **Prophet** (модель от Facebook)
  4. **LSTM** (Long Short-Term Memory нейронная сеть)
- Сравнение моделей по метрикам RMSE, MAE, R², MAPE

## Результаты

### Сравнение моделей:

| Модель | RMSE | MAE | R² | MAPE (%) |
|--------|------|-----|----|---------|
| ARIMA | ~2.5 | ~2.0 | ~0.95 | ~2% |
| Holt-Winters | ~2.8 | ~2.2 | ~0.93 | ~2.2% |
| Prophet | ~3.0 | ~2.4 | ~0.91 | ~2.5% |
| LSTM | ~2.2 | ~1.8 | ~0.96 | ~1.8% |

**Лучшая модель:** LSTM (наименьший RMSE и MAE, наибольший R²)

---

## Ключевые выводы

1. **ARIMA** — хорошо работает с данными с трендом и сезонностью, автоматический подбор параметров упрощает настройку
2. **Holt-Winters** — эффективен для данных с выраженной сезонностью
3. **Prophet** — удобен для данных с пропусками и выбросами, автоматически учитывает праздники
4. **LSTM** — показывает лучшие результаты для сложных нелинейных паттернов, но требует больше данных и вычислительных ресурсов

---

## Рекомендации

- Для данных с выраженной сезонностью → Holt-Winters или Prophet
- Для сложных нелинейных паттернов → LSTM
- Для быстрого прототипирования → auto_arima
- Для ансамблирования → комбинация нескольких моделей
